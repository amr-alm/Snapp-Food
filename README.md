# Snapp-Food | Java Food Ordering Application

**Team programming project · Java · Object-Oriented Programming**

An educational Java application inspired by online food and grocery ordering platforms. The project brings together user-facing shopping workflows and administrative functionality as a practical exercise in object-oriented application development.

## Functionality

The existing project documentation describes:

- User login and registration.
- Separate administrator and client functionality.
- Restaurant and supermarket sections.
- Product search and menu browsing.
- Shopping-cart management and checkout workflows.
- Order history.
- A graphical user interface.

Checkout is described as an application workflow; this documentation makes no claim of a production payment integration or audited transaction security.

## Engineering Focus

The project applies object-oriented programming to model the entities and interactions involved in an ordering application. Its academic focus is organizing a larger Java program around related responsibilities and connecting user interactions with application behavior.
